Proyecto Final - Rendimiento con Algoritmos de Ordenamiento y Búsqueda
Descripción

Este proyecto fue desarrollado como parte del curso de Estructura de Datos y Algoritmos. La aplicación simula la gestión de un catálogo de productos para una tienda en línea, implementando diferentes algoritmos de ordenamiento y búsqueda para analizar su rendimiento.

Funcionalidades
Generación automática de productos.
Gestión de un catálogo de productos.

Ordenamiento utilizando:
Merge Sort
Quick Sort
Heap Sort

Ordenamiento por:
Precio
Calificación
ID

Búsqueda:
Binaria por ID
Lineal por ID
Lineal por nombre

Medición del tiempo de ejecución de los algoritmos.
Interfaz gráfica desarrollada con Java Swing.
Arquitectura basada en programación orientada a objetos.

Tecnologías utilizadas
Java
Maven
Java Swing
GitHub

Integrantes
Lorena Vega

Objetivo

Analizar y comparar el rendimiento de diferentes algoritmos de ordenamiento y búsqueda aplicados a un conjunto de datos que representa un catálogo de productos, relacionando los resultados obtenidos con la teoría estudiada en el curso.
